One word that describes my Wi-Fi, for make.fun's
**u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72** bounty: **Catfishing**.

Home Wi-Fi constantly shows full bars and "Connected" while delivering no
internet at all — it lured you in with a fake profile, then nothing behind
it. The joke lands in one beat, it is true of every router that has ever
lied about its signal, and it is not the word the crowd reached for (the
field is piled onto "Gaslighting" and "Ghosting").

## How it works

`main.py` (Python 3.13, no dependencies, no network) scores a shortlist of
candidate words against the judge's published brief — on-subject fit, laugh,
truth, freshness, instant readability, in that order — picks the winner and
writes exactly that word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (10 bytes, no
trailing newline), inside the 1–20 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
cat out/entry.txt                         # Catfishing
```
